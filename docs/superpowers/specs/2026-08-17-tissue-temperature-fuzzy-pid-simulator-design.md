# 组织升温与模糊 PID 激光功率控制仿真设计

日期：2026-08-17

## 1. 项目目的

开发一个可在 Windows 上直接运行的 Python 桌面程序，用一阶组织热模型演示激光加热、温度测量、卡尔曼估计和闭环功率控制。程序同时服务于两个用途：

1. 帮助初学者理解组织升温、PID、模糊 PID 和卡尔曼滤波之间的数据关系。
2. 生成曲线、指标和参数记录，作为联系课题组时可以展示的阶段性学习成果。

程序参考马一鸣、孙明建团队论文公开摘要中的技术结构，即模型预测与观测、卡尔曼温度估计和模糊 PID 功率调节。公开资料没有提供完整的控制参数和模糊规则表，因此默认值和规则属于教学仿真假设，界面和导出文件必须明确标注，不能称为论文复现参数。

## 2. 技术方案

采用 Tkinter 构建 Windows 桌面界面，将 Matplotlib 图表嵌入窗口。数值计算使用 NumPy。

采用该方案的原因：

- 当前电脑上的 Python 3.14、Python 3.13 和已有虚拟环境均已验证可以创建 Tkinter 8.6 窗口。
- 不需要浏览器或额外的 Web 框架。
- Tkinter 适合参数输入、滑块、复选框和导出按钮，Matplotlib 适合多曲线科学绘图。
- 计算核心与界面分离，便于自动测试，也方便以后替换为论文中的真实模型和参数。

## 4. 组织热模型

采用集总参数一阶热模型：

\[
\frac{dT}{dt}=-\frac{T-T_a}{\tau}+K_hu
\]

变量定义：

- \(T\)：组织真实温度，单位为 °C。
- \(T_a\)：环境与初始温度，默认 37 °C。
- \(\tau\)：组织热时间常数，单位为 s，数值越大表示散热越慢。
- \(K_h\)：归一化激光功率对应的升温增益，单位为 °C/s。
- \(u\)：激光功率，内部范围为 0 至 1，界面显示为 0% 至 100%。

使用固定步长离散积分。默认设置为 180 s 仿真时长和 0.1 s 步长。界面允许修改环境温度、目标温度、时间常数、加热增益、最大激光功率、仿真时长和步长。

该模型用于控制算法入门，不描述组织内部空间温度分布，也不代替 Pennes 生物传热模型。程序必须在说明文字中保留这一限制。

## 5. 温度测量与卡尔曼估计

仿真同时维护三种温度：

1. 热模型输出的真实温度 \(T\)。
2. 加入高斯白噪声后的测量温度 \(z\)。
3. 一维模型驱动卡尔曼滤波得到的估计温度 \(\hat T\)。

卡尔曼预测采用与组织热模型一致的离散状态方程，观测方程为：

\[
z_k=T_k+v_k
\]

其中 \(v_k\) 是测量噪声。界面允许开关卡尔曼反馈，并允许调节过程噪声方差 \(Q\)、测量噪声方差 \(R\) 和实际测量噪声标准差。关闭卡尔曼滤波后，控制器直接使用带噪测量温度；开启后，控制器使用估计温度。

仿真使用固定随机种子。经典 PID 和模糊 PID 对比时共用相同噪声序列，避免噪声差异干扰比较。

## 6. 经典 PID

控制器根据目标温度与反馈温度之差计算激光功率：

\[
u=K_pe+K_i\int e\,dt+K_d\frac{de}{dt}
\]

实现要求：

- 激光功率限制在用户设置的上下限内。
- 使用条件积分或回算方法防止积分饱和。
- 对微分项进行一阶低通滤波，减少测量噪声放大。
- 采用对测量值微分的形式，减轻目标温度突然变化引起的微分冲击。
- 界面允许调节 \(K_p\)、\(K_i\)、\(K_d\)、微分滤波系数和抗积分饱和参数。

## 7. 模糊 PID

模糊 PID 采用在线增益调度结构。基础增益由用户设置，模糊推理根据归一化温度误差 \(e\) 和误差变化率 \(de/dt\) 计算三个增量：

\[
K_p=K_{p0}+\Delta K_p
\]

\[
K_i=K_{i0}+\Delta K_i
\]

\[
K_d=K_{d0}+\Delta K_d
\]

输入使用五个语言变量：`NB`、`NS`、`ZO`、`PS`、`PB`，分别表示负大、负小、零、正小、正大。采用三角形或梯形隶属度函数和 5×5 规则表，通过加权平均得到输出。

规则设计遵循下列控制意图：

- 温差大时提高比例作用，加快升温，并限制积分累积。
- 接近目标温度时减小比例作用，逐步恢复积分作用，降低稳态误差。
- 温度变化过快或出现反向变化时提高微分作用，抑制超调。

界面允许调节基础 \(K_{p0}\)、\(K_{i0}\)、\(K_{d0}\)，误差归一化尺度、误差变化率尺度，以及三个增益修正上限。程序始终限制实时增益范围，避免负增益或异常大增益。

这些规则属于可解释的教学设计，不是论文规则表。以后获得论文正文和补充材料后，可只替换 `fuzzy_rules.py` 和默认参数，不改动界面与仿真主流程。

## 8. 桌面界面

窗口左侧为参数面板，右侧为四张曲线。参数按四组排列：

- 控制器：经典 PID 或模糊 PID、基础增益、模糊尺度、功率限制。
- 组织模型：环境温度、目标温度、时间常数和加热增益。
- 温度估计：测量噪声、卡尔曼开关、\(Q\) 和 \(R\)。
- 仿真设置：总时长、步长和随机种子。

目标温度和基础 `Kp`、`Ki`、`Kd` 同时提供滑块与数值输入框，两者保持同步。其他数量级跨度较大的参数使用数值输入框，方便输入较小的 `Q`、`R` 和模糊增益修正量。

右侧曲线：

1. 目标温度、真实温度、带噪测量温度和卡尔曼估计温度。
2. 激光功率。
3. 温度误差。
4. 实时 \(K_p\)、\(K_i\)、\(K_d\)。经典 PID 模式下三条增益曲线为常数。

按钮：

- `运行当前参数`
- `经典 PID 与模糊 PID 对比`
- `恢复默认参数`
- `导出结果`

程序不在拖动每个滑块时持续计算，避免界面卡顿。用户调整参数后点击运行按钮刷新曲线，保证操作可预测。

## 9. 性能指标

界面显示当前运行的指标：

- 最大超调量，单位为 °C 和百分比。
- 进入目标温差 10% 范围的上升时间。
- 仿真末段平均稳态误差。
- 控制温度平均绝对误差。
- 原始测量 RMSE。
- 卡尔曼估计 RMSE。
- 累计归一化激光能量 \(\int u\,dt\)。

RMSE 定义为：

\[
RMSE=\sqrt{\frac{1}{N}\sum_{k=1}^{N}(\hat T_k-T_k)^2}
\]

原始测量 RMSE 使用测量温度代替 \(\hat T\)。两个指标并列显示，用于判断卡尔曼滤波是否降低测温误差。

若响应在仿真时间内没有达到指标定义要求，上升时间显示为“未达到”，不返回误导性的数值。

## 10. 对比模式

对比模式使用完全相同的组织参数、初始温度、噪声序列和目标温度，分别运行经典 PID 与模糊 PID。

温度、功率和误差图显示两套控制结果。带噪测量点只显示一组，并降低透明度，避免图形过密。增益图显示模糊 PID 的时变增益和经典 PID 的常数增益。指标区域以表格形式并列显示两种控制器的超调、上升时间、稳态误差、平均绝对误差和累计激光能量。

对比结果只说明当前仿真模型和当前参数下的表现，不据此宣称模糊 PID 在真实治疗中一定优于经典 PID。

## 11. 导出结果

每次导出在 `outputs/` 中创建带时间戳的目录，包含：

- `curves.png`：四联图，白色背景，适合放入邮件或报告。
- `timeseries.csv`：时间、目标温度、真实温度、测量温度、估计温度、误差、功率和实时 PID 增益。
- `parameters.json`：所有输入参数、控制模式、随机种子和指标。
- `README.txt`：简短说明结果来自一阶教学模型，默认参数不是论文实验参数。

PNG 使用 Matplotlib 对象式接口和 `constrained_layout`，避免标题、图例和坐标轴重叠。颜色兼顾屏幕显示和色觉辨识，真实温度与估计温度使用不同线型。

## 12. 输入检查与错误处理

运行前检查：

- 所有数值输入都能转换为浮点数或整数。
- 时间常数、仿真时长和步长必须大于零。
- 仿真步数设置上限，避免错误参数造成长时间卡顿。
- 目标温度、环境温度、功率限制和控制增益必须处于预设的教学仿真范围。
- \(Q\)、\(R\) 和噪声标准差不能为负数。
- 最小激光功率不得大于最大激光功率。

输入有误时，窗口显示包含参数名称和允许范围的提示，不启动仿真。数值计算出现非有限值时立即终止，并提示用户恢复默认参数。

## 13. 自动测试

采用 Python 标准库 `unittest`，减少额外测试依赖。按测试驱动方式先写失败测试，再实现对应功能。

测试范围：

- 零激光功率时，高于环境温度的组织逐步降温。
- 正激光功率使组织升温，并趋向合理稳态。
- 经典 PID 输出满足功率限幅，积分器不会无限累积。
- 模糊推理在典型误差组合下给出预期方向的增益修正。
- 模糊 PID 的实时增益始终处于设定范围。
- 固定噪声条件下，卡尔曼估计 RMSE 小于原始测量 RMSE。
- 相同随机种子和参数产生完全相同的仿真数组。
- 指标计算能处理未达到目标温度、零误差和短仿真等边界条件。
- 导出文件包含必需列、参数来源声明和有效 PNG。
- 使用无显示后端完成一次程序核心烟雾测试。

Tkinter 控件不做逐像素自动测试。实现完成后在本机实际启动窗口，检查参数区域、按钮、四张曲线和中文文本是否完整显示，并验证导出操作。

## 14. 默认参数原则

默认参数在实现阶段通过以下标准确定：

- 从 37 °C 升到默认目标 43 °C 时，闭环响应能在 180 s 内进入稳态。
- 初始经典 PID 有可见但不过分夸张的控制过程。
- 默认模糊 PID 能展示在线增益变化，但不刻意调整成必然优于经典 PID。
- 测量噪声足以看出卡尔曼滤波效果，又不会遮住温度趋势。
- 默认激光满功率对应的稳态温升高于目标温升，保证模型具有控制余量。

默认数值将在测试和调参记录中注明为工程初值。后续若用于论文对照，必须使用正文给出的对象模型、实验条件和控制参数重新标定。
