# 组织升温与模糊 PID 激光功率控制仿真

这个项目用一个可以看懂、可以修改的数值模型，演示激光加热时温度控制器是怎样工作的。程序会模拟组织升温、测温噪声、卡尔曼温度估计、经典 PID 和模糊 PID，然后把结果画出来。

程序适合刚开始学习控制、单片机或光声测温的同学。它能帮助你看清楚一件事：控制器拿到的不是“完美温度”，而是带噪声的测量值；卡尔曼滤波先把这个测量值整理一下，PID 再根据温差决定激光功率。

> 这里的热参数、PID 参数和模糊规则是教学用的工程初值，不是论文中的原始实验参数。结果只能用来理解算法，不能用于真实治疗或临床判断。

## 先看懂一次仿真

每个时间步都会按下面的顺序计算：

1. 上一个时间步的激光功率作用到组织，得到新的真实温度。
2. 在真实温度上加入随机噪声，得到模拟测量温度。
3. 卡尔曼滤波器根据热模型预测温度，再用测量温度修正预测值。
4. 控制器计算目标温度与反馈温度的误差。
5. PID 或模糊 PID 把误差换算成下一步的激光功率。

因此，程序同时保存四种温度：

- 真实温度：热模型内部的温度，仿真中可以知道，真实实验中通常不知道。
- 带噪测量：模拟温度传感器直接读到的值。
- 卡尔曼估计：滤波器结合模型和测量得到的温度。
- 目标温度：控制器希望组织达到的温度。

## 组织升温模型

程序使用一阶集总热模型：

\[
\frac{dT}{dt}=-\frac{T-T_a}{\tau}+K_hu
\]

变量含义如下：

- `T`：组织当前温度，单位是摄氏度。
- `Ta`：环境温度，默认是 37 摄氏度。
- `tau`：热时间常数。它越大，组织升温和散热越慢。
- `Kh`：满功率时的升温增益，单位是摄氏度每秒。
- `u`：归一化激光功率，范围是 0 到 1。

第一项表示散热。组织温度高于环境温度时，这一项让温度下降。第二项表示激光带来的升温。

程序使用这个一阶模型的精确离散形式计算每一步，所以即使时间步长较大，零功率散热也不会不合理地穿过环境温度。仿真时长必须是时间步长的整数倍，避免曲线时间和实际积分时间不一致。

这个模型没有描述组织内部不同位置的温度差异，也没有加入血流灌注、光学吸收和空间热扩散。它适合学习控制回路，不等同于真实人体组织模型。

## 测温噪声和卡尔曼估计

程序先用真实温度生成模拟测量：

\[
z_k=T_k+v_k
\]

其中 `z` 是传感器读数，`v` 是随机测量噪声。

卡尔曼滤波器做两件事：

1. 根据上一步的温度、激光功率和热模型，预测这一步温度。
2. 比较预测值和带噪测量值，根据不确定度决定更相信哪一个。

界面中的 `Q` 是每个时间步加入的过程方差，`R` 是测量方差，二者单位都是摄氏度平方。`R` 越大，表示传感器越不可靠，滤波器会更多依赖模型；`Q` 越大，表示模型越不可靠，滤波器会更多依赖测量。

打开“使用卡尔曼估计反馈”后，控制器使用估计温度。关闭后，控制器直接使用带噪测量温度。这样可以直观看到测温质量对控制结果的影响。

## 经典 PID 在做什么

经典 PID 使用固定的三个增益：

\[
u=K_pe+K_i\int e\,dt+K_d\frac{de}{dt}
\]

其中 `e` 是目标温度减去反馈温度。

- `Kp` 负责看当前差多少。温差大时，比例项会要求更大的功率。
- `Ki` 负责消除长期剩下的小误差。
- `Kd` 负责看温度变化趋势。温度升得太快时，微分项会提前压低功率。

程序对功率设置上下限，并加入条件积分，避免激光已经满功率时积分项还一直变大。微分项使用测量温度的变化，并经过一阶滤波，减少噪声放大。

## 模糊 PID 在做什么

模糊 PID 不是另一个完全不同的控制器。它仍然使用 PID 公式，但会根据当前误差和误差变化率在线调整 `Kp`、`Ki`、`Kd`。

程序把误差分成五个语言等级：

- `NB`：负得很大
- `NS`：负得较小
- `ZO`：接近零
- `PS`：正得较小
- `PB`：正得很大

例如，目标温度是 43 摄氏度，而当前反馈温度只有 37 摄氏度，误差是一个较大的正值，规则会增加比例作用并减少积分累积，让系统先快速升温。温度接近目标时，比例修正会减小，积分作用逐渐恢复。温度上升过快时，微分作用会增加，用来压制超调。

规则表在 `fuzzy_rules.py` 中，代码注释也说明了它们是教学设计，不是从论文正文抄来的参数。

## 界面参数怎么调

建议先只改一项参数，再运行一次，这样容易看出变化。

| 参数 | 作用 | 调大后的常见现象 |
| --- | --- | --- |
| 目标温度 | 希望达到的温度 | 目标更高，升温时间通常更长 |
| 热时间常数 | 散热和升温的快慢 | 变大后响应更慢 |
| 激光加热增益 | 同样功率带来的升温速度 | 变大后升温更快 |
| `Kp` | 当前温差的作用 | 变大后响应更快，也可能超调 |
| `Ki` | 消除稳态误差 | 变大后消除误差更快，也可能产生振荡 |
| `Kd` | 根据变化趋势提前刹车 | 变大后通常能减小超调，但对噪声更敏感 |
| 测量噪声 | 传感器读数的随机波动 | 变大后原始测量更乱 |
| `Q`、`R` | 卡尔曼滤波对模型和测量的信任程度 | 改变估计曲线的平滑程度 |
| 时间步长 | 每次计算间隔 | 变大后计算更快，但时间分辨率更低 |

激光功率上下限用于限制控制器输出。默认最小功率为 0%，最大功率为 100%。

## 四张曲线怎么看

### 温度响应

黑色虚线是目标温度，蓝线是真实温度，灰色点是带噪测量，绿色线是卡尔曼估计。绿色线比灰色点平滑，并且应该大体跟随蓝线。

### 激光功率

这张图显示控制器每个时间步要求的激光功率百分比。开始升温时功率通常较大，接近目标后功率会下降到维持散热平衡所需的水平。

### 反馈温度误差

误差等于目标温度减去反馈温度。误差为正表示温度还不够高，误差为负表示温度超过目标。

### PID 实时增益

经典 PID 的三条增益曲线是水平线。模糊 PID 的曲线会随误差和变化率变化，这就是“自整定”的来源。

## 指标怎么理解

- 超调：真实温度超过目标温度的最高幅度。
- 超调率：超调量除以目标温差。
- 上升时间：真实温度第一次进入目标温差 10% 范围的时间。
- 稳态误差：仿真末段目标温度与真实温度的平均差。
- 控制平均绝对误差：整个仿真过程中真实温度与目标温度的平均绝对差。
- 原始测量均方根误差：带噪测量与真实温度的差距。
- 卡尔曼均方根误差：估计温度与真实温度的差距。它越小，说明当前仿真假设下滤波效果越好。
- 归一化功率积分：功率曲线对时间的积分，单位是秒。没有给出激光器额定功率时，不能把它直接换算成焦耳。

仿真中知道真实温度，所以可以计算这两个均方根误差。真实实验通常不知道绝对真实温度，需要用经过标定的参考温度计做对照。

## 经典 PID 与模糊 PID 对比

点击“经典 PID 与模糊 PID 对比”后，程序用相同的组织参数、目标温度和噪声序列运行两次控制器。这样两条曲线的差异主要来自控制算法，而不是随机噪声不同。

对比结果只能说明当前模型和当前参数下的差异，不能据此断言模糊 PID 在真实治疗中一定更好。

## 导出结果

点击“导出结果”并选择文件夹后，程序会创建一个带时间的结果目录：

- `curves.png`：当前窗口中的四联图。
- `timeseries.csv`：时间、目标温度、真实温度、测量温度、估计温度、误差、功率和实时增益。
- `parameters.json`：全部输入参数和性能指标。
- `README.txt`：本次结果的参数来源和适用范围说明。

在对比模式下，根目录保存经典 PID 的结果，`fuzzy_pid` 子目录保存模糊 PID 的结果。

## 这个仿真不能替代什么

它不能替代真实组织实验，也不能直接给出治疗功率。真实研究还需要加入 Pennes 生物传热方程、组织光学参数、血流灌注、空间温度场、测温探头误差和实验标定。

这个项目的用途是把控制算法的输入、计算和输出连起来，让初学者可以改参数、看曲线、读代码，再逐步换成自己的实验数据和更完整的组织模型。
